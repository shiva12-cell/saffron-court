# Saffron Court — restaurant data

Saffron Court is a rooftop restaurant in Dubai. Rania, the manager, runs it on paper and WhatsApp and wants one
internal application her team can use: Menu & Orders, Reservations, Kitchen, Inventory, Dashboard.

## What is in this folder
- `data/menu.csv` — dishes, categories, prices in AED, allergens, kids_friendly. One dish has no price.
- `data/tables.csv` — 14 tables with seat counts and zones.
- `data/reservations-tonight.csv` — tonight's bookings.
- `data/orders-yesterday.csv` — every order line from yesterday, with the price actually charged.
- `data/recipes.csv` — ingredients and quantity per portion for each dish.
- `data/inventory.csv` — current stock per ingredient with units and reorder levels.
- `data/staff.csv` — the team.
- `data/house-rules.docx` — Rania's rules for bills, reservations, kitchen, inventory and end of day.
- `app/` — empty. The application is built here.
